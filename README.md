# crossstitch_tools_github

GitHub Pages 用にまとめた1リポジトリ構成です。

## 構成
- `index.html`
  トップページ
- `dot/`
  ドット絵向けツール
- `photo/`
  通常画像向けツール
- `.nojekyll`

## 公開方法
1. このフォルダの中身を1つのGitHubリポジトリにアップロード
2. GitHub Pages を有効化
3. 公開URLを開く

## 使い方
- トップページから `dot` か `photo` を選ぶ
- 画像を選択またはドラッグ＆ドロップする
- 必要に応じて設定を調整する
- PNG保存またはPDF保存を使う
